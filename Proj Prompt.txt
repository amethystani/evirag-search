EVIRAG
Evidence-Centric, Disagreement-Aware Retrieval-Augmented Generation for Scientific Literature

1. Problem Statement

Retrieval-Augmented Generation (RAG) systems are typically optimized to produce a single confident answer by aggregating retrieved documents. While effective for factual lookup, this paradigm is fundamentally misaligned with scientific knowledge, which is:

inherently disputed

context-dependent

evolving over time

supported by heterogeneous and sometimes contradictory evidence

When applied to scientific literature, standard RAG systems often:

collapse disagreement into a false consensus

hallucinate confidence where evidence is mixed

suppress minority or contradictory findings

fail to explain why sources disagree

Existing RAG frameworks lack explicit mechanisms to model evidence conflict, reason over disagreement, ground claims in visual experimental evidence, or calibrate confidence based on evidence structure rather than fluency.


2. Project Objective

The objective of EVIRAG is to design and implement a local-first, evidence-centric retrieval system that:

Treats evidence and disagreement as first-class signals

Surfaces competing scientific viewpoints rather than hiding them

Verifies explanations against retrieved evidence before synthesis

Uses role-specialized, constrained agents to stress-test claims

Integrates textual and visual scientific evidence

Produces calibrated confidence grounded in evidence agreement and conflict

Operates entirely using local, open-weight models without external APIs


3. Core Design Philosophy

EVIRAG is guided by the following principles:

Evidence over fluency

Disagreement over consensus

Verification before synthesis

Constrained deliberative agents over autonomous agents

Hybrid SLM–LLM–VLM architecture for efficiency and rigor

Reproducible, local deployment over opaque cloud services

8. Explanation-First Verification (X-IR)
8.1 Hypothesis Generation

Instead of answering directly, EVIRAG first generates a structured explanation hypothesis.

Output schema:

{
  "central_hypothesis": "...",
  "supporting_claims": [...],
  "assumptions": [...],
  "expected_counterclaims": [...]
}


Purpose:

make reasoning explicit

convert explanations into verifiable units

prevent hallucinated conclusions

Models:

Primary: phi-3:mini

Escalation: llama3:latest (if low confidence)

9. Multi-Agent Deliberative Retrieval (MAD-RAG)
9.1 Agent Design

Agents are role-specialized epistemic agents with constrained autonomy.

Agent	Objective	Model
Precision Agent	High-confidence support	llama3
Recall Agent	Broad coverage	qwen3:4b
Skeptic Agent	Actively find contradictions	llama3
Counterfactual Agent	Attempt disproof	deepseek-r1:7b

Each agent:

receives the hypothesis

observes system state

executes a distinct retrieval and reasoning policy

9.2 Agent Outputs

Each agent returns:

retrieved chunks

extracted claims

stance (support / oppose)

internal confidence signals

10. Claim Extraction Layer
10.1 Claim Filtering (SLM)

Model: phi-3:mini

Filters candidate sentences likely to contain factual claims

Removes background and non-assertive text

10.2 Atomic Claim Extraction (LLM)

Model: llama3:latest

Converts filtered sentences into atomic, normalized claims

Preserves source attribution

Claims become the fundamental reasoning unit, not documents.

11. Claim Relationship Analysis
11.1 Pre-filtering (SLM)

phi-3:mini identifies likely:

support pairs

contradiction pairs

neutral pairs

11.2 Verification (LLM)

llama3 performs NLI-style reasoning:

entailment

contradiction

neutral

Only ambiguous or high-impact pairs are escalated.

12. Disagreement Graph Construction

A graph is constructed where:

nodes: claims (textual + visual)

edges: support or contradiction

weights: confidence and evidence strength

Tooling:

Disagreement density

Conflict ratio

Visual–text mismatch scores (from CLIP)

These metrics directly influence synthesis and confidence.

14. Deliberative Multi-View Synthesis

Instead of a single answer, EVIRAG produces:

Dominant view

Alternative views

Minority or outlier views

Each view includes:

supporting claims

source count

Model:

phi-3:mini (primary)

15. Confidence Calibration

Confidence is derived, not predicted.

Factors:

contradiction severity

visual evidence alignment

- 6 contradict
- Visual evidence partially ambiguous
- Disagreement concentrated on theoretical interpretation
